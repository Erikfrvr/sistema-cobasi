# Sistema de Caixa Integrado - Amigo Cobasi

**Projeto de Banco de Dados - UC10 (Senac)**
Este repositório contém a modelagem e os scripts SQL para a implementação de um sistema de caixa de loja física integrado ao programa de fidelidade "Amigo Cobasi". O sistema registra vendas, gerencia pagamentos, atualiza o estoque e computa os pontos de fidelidade do cliente.

## Equipe
* **Erik Mauricio:** Estrutura de Clientes/Vendas, Transações Complexas e Normalização de Dados.
* **Gabriel:** Estrutura de Produtos, Views, Segurança/Permissões e Modelagem/UML.
* **Rafael:** Geração da Massa de Dados (Testes), Qualidade e Compilação da Documentação.

## Pré-requisitos
Para executar este projeto na sua máquina, você precisará ter:
* [XAMPP](https://www.apachefriends.org/pt_br/index.html) (com os módulos Apache e MySQL ativos).
* Um editor de texto de sua preferência, como [Notepad++](https://notepad-plus-plus.org/downloads/) ou VS Code, para visualizar os scripts.
* [Git](https://git-scm.com/) para clonar o repositório.

Siga o passo a passo abaixo para rodar o banco de dados localmente usando o XAMPP:
